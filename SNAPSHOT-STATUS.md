# Состояние проекта

Проект инициализирован как Git-репозиторий для abuzo/pocketcard-ios. Нативная сборка Xcode и проверка локального фотосценария выполнены на Mac. Актуальные результаты и ограничения: [docs/VERIFICATION-MAC.md](docs/VERIFICATION-MAC.md). Исходный отчёт Linux сохранён в docs/VERIFICATION.md как история поставки.
